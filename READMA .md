# Tiny Compiler

## About
Tiny Compiler is a compiler project developed using Python.

## Technologies Used
- Python
- PLY (Python Lex-Yacc)

## Project Components
- Lexical Analysis
- Syntax Analysis
- Semantic Analysis
- Intermediate Code Generation
- Code Optimization
- Code Generation
- Simulation

- main.py
- lexer.py
- parser.py
- semantic_analyzer.py
- intermediate.py
- optimizer.py
- codegen.py
- simulator.py
